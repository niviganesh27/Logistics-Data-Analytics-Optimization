# Logistics Data Analytics & Predictive Optimization

End-to-end logistics data analytics project developed during a Logistics Data Analyst internship at YuvaIntern.

## Workflow
Strategic Planning → Data Preprocessing → EDA & Visualization → Predictive Modeling → Delivery Risk → Operational Optimization

## Technologies
Python, Pandas, NumPy, Matplotlib, Scikit-learn, Jupyter Notebook

## Notebooks
1. `01_strategic_planning.ipynb`
2. `02_data_preprocessing.ipynb`
3. `03_eda_and_visualization.ipynb`
4. `04_predictive_modeling_and_optimization.ipynb`

## Dataset
The repository uses a simulated logistics dataset for educational and analytical purposes. It is not confidential company data.

## Key Analysis
- Logistics KPI planning
- Data cleaning and preprocessing
- Exploratory data analysis
- Delivery-time visualization
- Regression model comparison
- Cross-validation
- Hyperparameter tuning
- Delivery-risk classification
- Route and resource optimization logic

## Run
```bash
pip install -r requirements.txt
jupyter notebook
```

Open the notebooks in order from Week 1 to Week 4.
